【一、单项计分标准】
来源：学校计分表（计算公式.xlsx）的公式链。
计分语义：每个项目有一串"阈值→得分"的档位表，
按顺序从上往下查，学生成绩达到的第一个档位就是得分；
未达到最低档位 → 0分。
（例如女生50米：≤7.5→100、≤7.6→95、≤7.7→90、≤8.0→85，
则 7.8秒、7.9秒 都落在"≤8.0"档 → 85分）

1. 身高体重（BMI）
   BMI = 体重(kg) ÷ 身高(m)²
   男生：17.9~23.9 → 100分；≥28 → 60分；其余 → 80分
   女生：17.2~23.9 → 100分；≥28 → 60分；其余 → 80分
   （学校计分表的简化三档规则）

【二、总分与等级】
   总分 = 身高体重×15% + 肺活量×15% + 50米跑×20%
        + 立定跳远×10% + 坐位体前屈×10%
        + 耐力跑(1000/800米)×20% + 力量(引体/仰卧起坐)×10%
   （权重合计100%，与学校计分表一致）
   总分保留1位小数（四舍五入）。
   等级：≥90 优秀；80~89.9 良好；60~79.9 及格；<60 不及格。

【三、缺项处理】
   任何一项没有成绩 → 该学生"缺项"：
   - 缺项学生不计算总分、不评等级
   - 缺项学生【不计入】全班平均分、及格率、优良率等总体统计
   - 班级分析页与PDF会显示"缺项人数"
   - 各项目统计时：缺该项成绩的学生不参与该项目平均分计算

【四、统计口径】
   1. 全班平均分 = 完整录入学生的总分总和 ÷ 完整录入人数
      （示例：1班初测1480人中1441人完整录入，按1441人算）
   2. 及格率 = 总分≥60的人数 ÷ 完整录入人数
   3. 优良率 = 总分≥80的人数 ÷ 完整录入人数
   4. 各项目平均分 = 该项目填了成绩的学生的得分总和 ÷ 人数
   5. "男女合并"的平均 = 男生该分总和+女生该分总和 ÷ 男女总人数
      （按人数加权，不是男女平均的简单平均）

【五、优势项目与薄弱项目判定】
   判定前先算"各项目均分"：
   = 7个项目（身高体重/肺活量/50米/立定跳远/坐位体前屈/
     耐力跑(男女合并)/力量(男女合并)）的【全班平均分】的算术平均。
   薄弱项（满足任意一条即列入，按平均分从低到高排列）：
     ① 平均分是全班最低的2个项目之一
     ② 及格率低于70%
     ③ 平均分比"各项目均分"低5分以上
   优势项（满足任意一条即列入）：
     ① 平均分是全班最高的2个项目之一
     ② 平均分≥85分 且 及格率≥95%
   说明：低5分、70%、最低2项、85/95等阈值均为软件内置的
   经验性参数（非国家标准），可按老师要求调整。

【六、个人薄弱项判定（个人报告）】
   必练项目（红色）：单项得分 < 60的项目，
     按"加权失分"排序：加权失分 = (100-得分) × 项目权重，
     权重越大、得分越低越靠前。
   相对薄弱项目（黄色）：得分≥60 但低于"个人总分-10分"的项目。
   训练建议：取排序前3项，从训练知识库组合生成。

【七、进步/退步判定（纵向对比）】
   按学籍号匹配同一学生前后两次成绩；
   总分变化 ≥ +1分 → 进步名单；≤ -1分 → 退步名单；
   |变化| < 1分 → 持平，不进名单。

【八、排名规则】
   按总分从高到低排名；缺项学生不参与排名，排在最后。
   性别排名 = 在同性别学生中的排名。

【九、班级横向对比口径】
   每个班级使用其【最新的测试批次】的数据进行对比。

【十、训练计划生成规则】
   1. 输入：班级薄弱项（男女各取前3项）+ 周数（默认4周）
   2. 每周1节体育课模板：
      热身10分钟（动态热身4项）→ 主体训练25分钟 →
      放松整理5分钟 → 课后作业
   3. 主体训练按薄弱项的训练方法轮换组合：
      第1周方法A+B、第2周A+C、第3周B+C、第4周A+B
   4. 第4周 = 模拟测试课（完整测8项，供复测对比）
   5. 男生主练男生项目（1000米/引体向上），女生主练女生项目
   6. 若班级无薄弱项 → 生成"综合保持训练"计划
   7. 课后作业取自对应项目的自主练习建议

公式表后告知，即可按新标准更新软件。
